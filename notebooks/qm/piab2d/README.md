# PIAB2D computational laboratories

Laboratories are grouped first by Schrödinger equation and then by solution
family:

- [`tise/analytical/`](tise/analytical/README.md) contains maintained analytical
  stationary-state laboratories.
- [`tise/numerical/`](tise/numerical/README.md) preserves an oblique-coordinate
  boundary-condition prototype pending correction and consolidation.
- [`tdse/numerical/`](tdse/numerical/README.md) records the location and current
  unimplemented status of numerical time propagation.
