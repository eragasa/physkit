# Quantum-mechanics laboratories

Maintained quantum laboratories are organized by model family and spatial dimension:

- [`piab1d/`](piab1d/README.md)
- [`piab2d/`](piab2d/README.md)
- [`piab3d/`](piab3d/README.md)
- [`qho1d/`](qho1d/README.md)

Each directory owns laboratory configuration, visualization, interpretation,
and exercises. Reusable models and analysis actions live in
`projectkoios.physkit`.
