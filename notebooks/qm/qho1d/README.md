# QHO1D computational laboratories

- [`qho1d__finite_difference.ipynb`](qho1d__finite_difference.ipynb) owns the
  bounded coordinate-grid representation, low-energy comparison, and shifted
  eigenfunction visualization.

The repository-root `qho-hermite-basis.ipynb` remains a separate candidate for
migration because it studies function-basis truncation rather than a spatial
finite-difference grid.
