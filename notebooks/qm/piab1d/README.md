# PIAB1D computational laboratories

- [`piab1d.ipynb`](piab1d.ipynb): Dirichlet-grid presentation, analytical and finite-difference spectra, discretization error, stationary states, probability density, and represented Hamiltonian;
- [`piab1d__time_evolution.ipynb`](piab1d__time_evolution.ipynb): analytical spectral propagation;
- [`piab1d__basis_projection.ipynb`](piab1d__basis_projection.ipynb): Gaussian-state normalization and energy-basis projection;
- [`piab1d__canonical_probabilities.ipynb`](piab1d__canonical_probabilities.ipynb): normalized single-particle canonical probabilities on a finite PIAB1D level inventory; and
- [`piab1d__fermions.ipynb`](piab1d__fermions.ipynb): continuous and discrete Fermi--Dirac occupations and spatial number density.
