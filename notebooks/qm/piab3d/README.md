# PIAB3D computational laboratories

- [`piab3d.ipynb`](piab3d.ipynb): analytical homogeneous-Dirichlet energies of a rectangular cuboid, cubic permutation degeneracy, and orthorhombic splitting.
- [`piab3d__eigenfunctions.ipynb`](piab3d__eigenfunctions.ipynb): normalized analytical Cartesian plane slices and probability-density heatmaps.

Finite-difference PIAB3D analysis remains proposed work and is not represented
as a completed laboratory.
