# Thermal-physics computational laboratories

This directory mirrors the reusable package hierarchy beneath
`projectkoios.physkit.thermal`.

- [`statmech/`](statmech/README.md) contains statistical-mechanics and kinetic-theory laboratories.
- [`thermo/`](thermo/README.md) contains thermodynamic-property and equation-of-state laboratories.
- [`transport/`](transport/README.md) contains thermal-transport and interfacial phase-change laboratories.

Reusable models, unit conversion, evaluators, and solvers belong in
`src/python/projectkoios/physkit/thermal/`. Notebooks retain instructional
sequencing, visualization, bounded checks, interpretation, and exercises.
