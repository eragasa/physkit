# Two-dimensional effective-mass laboratories

- [`primitive-cell-methodological-review.ipynb`](primitive-cell-methodological-review.ipynb)
  reviews direct/reciprocal geometry, metal-unit conversion, Cartesian
  effective mass, Bloch-mode energies, cell normalization, and primitive
  translation phases before a separate three-dimensional implementation.

This maintained two-dimensional laboratory uses illustrative synthetic basis
and mass values. It provides software and numerical-verification evidence for
the documented idealized model, not a material-specific band structure or a
replacement for Quantum ESPRESSO.
