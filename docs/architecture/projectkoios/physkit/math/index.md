# Package `projectkoios.physkit.math`

## Current responsibility

`projectkoios.physkit.math` owns reusable mathematical representations and
numerical evaluators that are not specific to one physical model. Mathematical
lesson narrative and experiments remain in lecture notes and notebooks.

## Public contract

Defining modules are the preferred import locations. The package does not
aggregate every mathematical implementation through its `__init__.py`.
