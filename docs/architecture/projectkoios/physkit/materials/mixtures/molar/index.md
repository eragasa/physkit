# `projectkoios.physkit.materials.mixtures.molar`

This module owns:

- [`MolarMixture`](MolarMixture/index.md), an ordered amount representation;
- [`MassMixture`](MassMixture/index.md), an ordered mass representation; and
- [`MixtureCompositionConverter`](MixtureCompositionConverter/index.md), the
  typed transformation between those representations.

Immutable requests and results retain conversion context and target units.
