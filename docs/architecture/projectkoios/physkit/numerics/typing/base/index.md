# Module `projectkoios.physkit.numerics.typing.base`

## Current responsibility

The module defines backend-independent built-in real, complex, and integer
scalar aliases for numerical implementations.

## Public contract

`RealScalar`, `ComplexScalar`, and `IntegerScalar` denote the corresponding
built-in scalar types. The module contains no conversion or validation policy.
