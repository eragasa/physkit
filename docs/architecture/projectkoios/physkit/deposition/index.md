# `projectkoios.physkit.deposition`

This package owns geometric transport models for physical deposition.

- [`geometry`](geometry/index.md) owns idealized point-source geometry.
- [`surface_source`](surface_source/index.md) owns finite emitting-surface geometry.

Phase-change emission belongs separately to
[`thermal.transport.phase_change`](../thermal/transport/phase_change/index.md).
