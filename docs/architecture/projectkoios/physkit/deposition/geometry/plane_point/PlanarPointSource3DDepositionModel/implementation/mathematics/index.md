# Mathematics

For source-plane separation $h>0$ and lateral offset $\ell\geq0$, isotropic
inverse-square spreading and substrate projection give

$$
\frac{d(\ell)}{d(0)}=\left[1+(\ell/h)^2\right]^{-3/2}.
$$

The ratio is dimensionless. Compatible physical length units are converted
before $\ell/h$ is formed.
