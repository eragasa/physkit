# `PlanarDiskSource3DDepositionModel`

`PlanarDiskSource3DDepositionModel` represents a finite circular source below a
parallel substrate. It owns positive unit-bearing separation and radius values
and a nonnegative unitless cosine exponent.

The public operation requires explicit polar quadrature settings and returns a
normalized unitless thickness profile. See the
[implementation](implementation/index.md).
