# Package `projectkoios.physkit.thermal`

## Current responsibility

`projectkoios.physkit.thermal` groups reusable thermodynamics,
statistical-mechanics, and thermal-transport model families. The package
separates thermodynamic property models, statistical ensembles, kinetic-theory
distributions, and interfacial transport.

## Public contract

Defining modules are the preferred import locations. This package does not
aggregate implementation classes through its `__init__.py`.
