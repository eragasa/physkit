# `ThermalDeBroglieWavelengthModel` implementation

The model converts mass and temperature to SI units, evaluates the canonical
closed form in binary64 arithmetic, and converts the wavelength to the requested
compatible length unit. Degeneracy evaluation converts number density and
wavelength to reciprocal cubic metres and metres before forming the unitless
product.
