# Testing

Software-verification tests compare wavelength evaluation with the documented
closed form, check $T^{-1/2}$ scaling, exercise compatible unit conversion, and
verify explicitly unitless $n\lambda_T^3$ results. The computational laboratory
adds an independent numerical Gaussian-quadrature route.

These checks establish implementation and numerical agreement with the stated
mathematics. They do not establish material-specific scientific validation.
