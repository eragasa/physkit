# Module `projectkoios.physkit.thermal.statmech.distributions.occupations.base`

## Current responsibility

This module owns the closed statistic identifier and shared unit-aware request
and response records. It converts compatible energy and temperature quantities
to SI only when constructing the internal dimensionless exponent.

## Records

- `IdealOccupationStatistic`
- `IdealOccupationEvaluationRequest`
- `IdealOccupationEvaluation`

Concrete formulas remain with their defining distribution packages.
