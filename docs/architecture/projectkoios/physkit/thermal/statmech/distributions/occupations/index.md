# Package `projectkoios.physkit.thermal.statmech.distributions.occupations`

## Current responsibility

This package owns ideal Fermi--Dirac, Bose--Einstein, and Maxwell--Boltzmann
occupation factors evaluated from explicit physical energies, chemical
potential, and absolute temperature. Occupation factors are explicitly unitless.
