# Mathematics

For positive mean free path $\lambda$ and positive characteristic length $L$,
the implementation evaluates

$$
\mathrm{Kn}=\frac{\lambda}{L}.
$$

The maintained [lecture note](../../../../../../../../../../lecture-notes/statistical-mechanics/knudsen-number/index.md)
describes the scale comparison and explains why flow-regime classification is a
separate policy boundary.
