# Testing

Software-verification tests check compatible length conversion, exact ratio
values, explicit unitlessness, request correlation, and rejection of nonpositive
mean free paths. The laboratory additionally verifies inverse-pressure scaling
when composed with the hard-sphere ideal-gas mean-free-path model.

These checks establish only the represented mathematical ratio and idealized
composition; they do not validate a real flow regime.
