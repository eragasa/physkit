# Package `projectkoios.physkit.thermal.statmech`

## Current responsibility

`projectkoios.physkit.thermal.statmech` owns reusable statistical-mechanics models,
state records, and numerical actions whose assumptions and units are explicit.
It does not own curriculum sequencing, plotting, experimental validation, or
material-specific acceptance policy.

## Public contract

Defining modules are the preferred import locations. The package does not
aggregate every implementation through its `__init__.py`.
