# Testing

Software-verification tests check unit-bearing finite spectra, correlation with
the request, agreement with the Wien limit at large $x$, agreement with the
Rayleigh--Jeans limit at small $x$, and rejection of zero wavelength. The
laboratory verifies both approximation regimes on many represented coordinates
and checks the retained plot data.

These checks establish agreement with the documented mathematical model, not
material-specific scientific validation.
