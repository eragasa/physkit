# Testing

Software-verification tests check pure-component limits, the equimolar closed
form, component-exchange symmetry, affine temperature conversion, explicit
molar units, and composition rejection. The laboratory additionally checks
represented local curvature at two illustrative temperatures and verifies the
retained plot.

The checks establish agreement with the stated regular-solution mathematics.
They do not establish coexistence compositions or material-specific validation.
