# Testing

Software-verification tests check separate coefficient-weighted one-way fluxes,
positive evaporation and condensation components, signed net flux, mass-flux
conversion, compatible output units, and retention of condensation-dominated
negative flux. The laboratory independently integrates the positive Maxwell
normal-velocity moment and checks agreement with the analytical evaluator.

These checks establish agreement with the stated classical three-dimensional
ideal-gas model. They do not validate interfacial coefficients or a real
material process.
