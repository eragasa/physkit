# `BaseQuantumModel3D`

## Responsibility

`BaseQuantumModel3D` is the nominal abstract base for physical models with fixed
spatial dimension `3`. It does not select geometry, boundary conditions,
solution method, or numerical representation.

## Local mapping

- Code: `src/python/projectkoios/physkit/qm/models/model3d.py::BaseQuantumModel3D`
- Concrete model tests: `tests/projectkoios/physkit/qm/piab3d/base/test__Piab3D__init.py`
