# `GaussianWavePacket1DInitialState`

## Responsibility

`GaussianWavePacket1DInitialState` represents one configured Gaussian packet at
the initial time. Its keyword-only `evaluate(coordinates=...)` action returns a
`SampledQuantumState1D`; it does not perform time evolution.
