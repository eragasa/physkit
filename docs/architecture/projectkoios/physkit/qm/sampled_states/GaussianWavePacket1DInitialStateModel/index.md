# `GaussianWavePacket1DInitialStateModel`

## Responsibility

`GaussianWavePacket1DInitialStateModel` immutably represents the initial packet
center, positive Gaussian width, and plane-wave wavenumber. Each constructor
argument is checked by its owner-local `_check_arg_<name>` method.
