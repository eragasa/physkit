# `SampledQuantumState1D`

## Responsibility

`SampledQuantumState1D` correlates one-dimensional coordinates with the complex
amplitudes of one general quantum state. It is not identified as a Hamiltonian
eigenfunction. Its `normalize(quadrature_weights=...)` action returns an
explicit normalization response.
