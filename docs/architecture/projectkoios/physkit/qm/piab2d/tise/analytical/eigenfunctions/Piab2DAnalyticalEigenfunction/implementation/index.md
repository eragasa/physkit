# Implementation

## Algorithm

1. Validate the PIAB2D model, positive built-in integer quantum numbers, and
   coordinate vectors.
2. Convert both coordinate vectors to the model length unit.
3. Reject coordinates outside their closed box intervals.
4. Evaluate the normalized separable sine-product eigenfunction as an outer
   product.
5. Return an immutable correlated eigenfunction evaluation.
