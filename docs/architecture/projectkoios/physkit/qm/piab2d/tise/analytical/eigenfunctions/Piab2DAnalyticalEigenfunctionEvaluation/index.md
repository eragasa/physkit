# `Piab2DAnalyticalEigenfunctionEvaluation`

## Responsibility

`Piab2DAnalyticalEigenfunctionEvaluation` is an immutable ResultObject correlating
one complete evaluation request, converted coordinate vectors, and sampled
normalized eigenvector amplitudes. It derives the sampled probability density
without changing the represented grid.
