# `Piab2DAnalyticalEigenfunction`

## Responsibility

`Piab2DAnalyticalEigenfunction` represents one stationary Hamiltonian
eigenvector identified by a PIAB2D model and positive $(n_x,n_y)$ quantum-number
pair. Its keyword-only `evaluate(...)` action samples that eigenvector through a
complete request and ActionObject.
