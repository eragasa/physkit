# Testing

The class-owned tests verify:

- normalized unit-square ground-state evaluation;
- homogeneous-Dirichlet boundary zeros;
- higher-state nodal structure;
- coordinate-unit conversion;
- physical amplitude and probability-density units;
- positive built-in integer quantum-number requirements; and
- rejection of coordinates outside the rectangle.

These checks establish software and numerical agreement with the documented
separable-rectangle equations. They do not constitute independent scientific
validation.
