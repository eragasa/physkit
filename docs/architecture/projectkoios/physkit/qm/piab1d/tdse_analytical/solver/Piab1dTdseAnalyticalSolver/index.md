# `Piab1dTdseAnalyticalSolver`

## Responsibility

`Piab1dTdseAnalyticalSolver` applies

$$
c_n(t)=c_n(0)e^{-iE_nt/\hbar}
$$

to a normalized coefficient vector, analytical TISE result, and ordered time
quantity beginning at zero. It returns a correlated analytical TDSE result and
introduces no time-stepping approximation.
