# `Piab1dTdseAnalyticalResults`

## Responsibility

`Piab1dTdseAnalyticalResults` is an immutable ResultObject correlating the
analytical TISE basis, normalized initial coefficients, ordered times, and
phase-evolved coefficients. It exposes spectral norms, conserved energy
expectation, and coordinate-space sampled-state evolution.
