# Implementation

`DimensionlessQho1DTiseFdSolver` builds a centered three-point Laplacian,
evaluates the harmonic potential on interior points, diagonalizes the real
symmetric Hamiltonian, and rescales eigenvector columns to rectangular-rule
continuous normalization.
