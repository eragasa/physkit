# Package `projectkoios.physkit.qm.piab3d`

## Current responsibility

This package owns the three-dimensional rectangular homogeneous-Dirichlet
particle-in-a-box model family. It does not represent periodic reciprocal-space
free particles or a finite-difference discretization.
