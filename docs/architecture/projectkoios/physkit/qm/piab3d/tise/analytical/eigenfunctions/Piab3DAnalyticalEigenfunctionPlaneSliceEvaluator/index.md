# `Piab3DAnalyticalEigenfunctionPlaneSliceEvaluator`

## Responsibility

This ActionObject evaluates a typed plane-slice request and returns normalized
three-dimensional eigenfunction amplitudes sampled on the requested Cartesian
plane. It does not independently normalize the two-dimensional slice.
