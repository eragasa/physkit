# `Piab3DAnalyticalSolution`

## Responsibility

`Piab3DAnalyticalSolution` is an immutable ResultObject correlating one
`Piab3D` model, a unique positive quantum-number triple inventory, and
nondecreasing energy quantities. Exact ties use lexicographic triple order.
