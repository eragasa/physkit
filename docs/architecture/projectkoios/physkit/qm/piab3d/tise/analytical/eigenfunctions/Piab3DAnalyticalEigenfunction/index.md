# `Piab3DAnalyticalEigenfunction`

## Responsibility

`Piab3DAnalyticalEigenfunction` represents one stationary Hamiltonian
eigenvector identified by a PIAB3D model and positive $(n_x,n_y,n_z)$ quantum
numbers. Its keyword-only `evaluate_plane_slice(...)` action returns a sampled
Cartesian plane response.
