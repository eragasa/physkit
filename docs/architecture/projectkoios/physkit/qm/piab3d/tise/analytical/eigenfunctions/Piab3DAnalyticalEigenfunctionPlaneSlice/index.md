# `Piab3DAnalyticalEigenfunctionPlaneSlice`

## Responsibility

`Piab3DAnalyticalEigenfunctionPlaneSlice` is an immutable response correlating
one complete evaluation request with converted in-plane coordinates, its fixed
coordinate, and sampled normalized eigenfunction amplitudes. It exposes the
deterministic in-plane axis mapping and unit-aware integrated plane density.
