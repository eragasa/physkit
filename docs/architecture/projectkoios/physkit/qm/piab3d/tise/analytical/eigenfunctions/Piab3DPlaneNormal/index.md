# `Piab3DPlaneNormal`

## Responsibility

`Piab3DPlaneNormal` identifies the Cartesian coordinate held fixed by a plane
slice. Members are `X`, `Y`, and `Z`, with represented values `"x"`, `"y"`,
and `"z"`.
