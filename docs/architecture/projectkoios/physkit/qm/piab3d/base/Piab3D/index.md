# `Piab3D`

## Responsibility

`Piab3D` is an immutable DataObject defining positive cuboid lengths
$(L_x,L_y,L_z)$, positive particle mass $m$, and one coherent numerical unit
system. Construction is keyword-only. It selects neither a solution method nor
a finite discretization.
