# `projectkoios.physkit.solidstate.phase_field.cahn_hilliard`

This package owns explicitly dimensionless constant-mobility Cahn--Hilliard
models:

- [`base`](base/index.md) owns shared reduced parameters;
- [`one_dimensional`](one_dimensional/index.md) owns periodic line evolution;
  and
- [`two_dimensional`](two_dimensional/index.md) owns periodic rectangular
  evolution.
