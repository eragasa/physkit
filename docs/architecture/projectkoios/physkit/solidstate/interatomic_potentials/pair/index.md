# `projectkoios.physkit.solidstate.interatomic_potentials.pair`

This package owns radial pair-potential contracts and concrete model families.

- [`base`](base/index.md) owns shared typed requests, results, and the abstract
  radial-potential boundary.
- [`lennard_jones_12_6`](lennard_jones_12_6/index.md) owns the Lennard--Jones
  12-6 parameter, model, and evaluator classes.
- [`morse`](morse/index.md) owns the Morse model and evaluator.
